Can I try Amfora today?

This website is a product preview. The source repository is currently private; invited collaborators can build and test Amfora using the getting-started guide. There is no public hosted demo or public release download yet.

Where are my files stored?

On the infrastructure you configure. Amfora includes internal object storage and supports external S3-compatible storage. The product website does not host your application or your files.

Do recipients need an account?

Shared download links and upload requests can be used without an Amfora account. You can protect links with a password and configure the controls available for each link.

Is this end-to-end encrypted?

No. Amfora is a self-hosted file-sharing application. Use HTTPS to protect traffic, configure your storage securely and manage access carefully. It does not currently provide end-to-end encryption.

Do I need every authentication provider?

No. Use local accounts and two-factor authentication if that meets your needs. External sign-in providers are optional; enable only the ones your team actually uses.
