# Public transfer artwork

`apps/web/public/art/amfora-glass.webp` was generated for Amfora on 2026-09-17 using the built in image generation tool. It depicts a cobalt glass amphora suspended above a plinth inside an illuminated architectural arch. It contains no third party logos or stock photography.

The generated 1024 × 1536 PNG was encoded as WebP (quality 86, 97,490 bytes) without changing the composition. The original is kept outside the repository.

The public transfer shell treats the image as decorative. Headlines, filenames, actions and status information remain real accessible HTML. The login artwork and design are unchanged.
