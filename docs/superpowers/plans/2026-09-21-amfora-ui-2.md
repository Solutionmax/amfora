# Amfora 2.0 Interface Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the postal interface with the approved warm, product-led design on every screen, and move all appearance state server-side with brandpack gating for the paid features.

**Architecture:** Tokens in `globals.css` drive restyled `components/ui` primitives with unchanged APIs. Two shells (`TransferShell` for public pages, `AppSidebar` plus page header for admin) are rewritten; pages are recomposed inside them while hooks, forms and endpoints stay. The server gains four app configs and a brandpack verifier reused from the update manifest code; `GET /app/info` enforces the gating.

**Tech Stack:** Next.js 15, React 19, Tailwind 4 (`@theme inline`), Radix primitives, next-intl (23 locales), Fastify + Zod + Prisma (SQLite), sharp, Node 22 test runner (`node --test` via tsx), Docker buildx.

**Spec:** `docs/superpowers/specs/2026-09-21-amfora-ui-2-design.md`. Visual source of truth: `design/mockups/2026-09-21-ui-2.html` (open it in a browser; its `<style>` block holds the exact values).

## Global Constraints

- Accent default `#0079D2`; ink `#0C1626`; background `#F6F9FD`; dark background `#0B1220`; dark accent `#3B9CF0`.
- Fonts: Archivo (display), Public Sans (body), JetBrains Mono (mono). Bricolage Grotesque and Plus Jakarta Sans removed. The ten selectable fonts in `font-picker-form.tsx` stay.
- Radius default `0.5rem`. Existing stored `appRadius` values are respected.
- Free: name, description, logo, accent, radius, font. Paid (pack-gated on the server): `appHideCredit`, `appBackground`, `appCustomCss`.
- No playful elements: no envelopes, stamps, seals, Delphic quotes, "Send something good" card.
- Motion 150 ms, opacity/transform only, `prefers-reduced-motion` respected.
- Copy in sentence case; buttons name the action. New strings in `messages/en-US.json` plus all 22 other locale files (CI checks key equality).
- Before every Docker build: `pnpm prettier --write "src/**/*.{ts,tsx,css}"` in `apps/web`. Build only with `bash infra/build-docker.sh <tag>`.
- Commits local only. No push, no tag, no live deployment. Staging container `amfora-brand-stage` on `:15487` (script `/root/amfora-brand-20260921/start-stage.sh`, change `IMAGE=`).
- Run from `apps/web`: `pnpm lint && pnpm type-check && pnpm test`. From `apps/server`: same. All green before each commit.

- [ ] **Step 3: Implement `cover-pick.ts`**

```ts
export type CoverKind = "video" | "image" | "document" | "archive" | "other";
export interface CoverFile { name: string; kind: CoverKind; previewUrl?: string }
export function pickCover(files: CoverFile[]): { kind: "image" | "gradient"; file: CoverFile } | null {
  const [first] = files;
  if (!first) return null;
  return { kind: first.kind === "image" ? "image" : "gradient", file: first };
}
```

```ts
// brandpack.ts
import { verifySigned } from "../update/manifest";
export const BRANDPACK_PURPOSE = "amfora-brandpack";
export interface Brandpack { organisation: string; issuedAt: string }
export function verifyBrandpack(token: string, publicKeyHex: string): Brandpack | null {
  const payload = verifySigned(token, publicKeyHex, BRANDPACK_PURPOSE);
  if (!payload) return null;
  const { organisation, issuedAt } = payload as Partial<Brandpack>;
  if (typeof organisation !== "string" || typeof issuedAt !== "string" || !organisation) return null;
  return { organisation, issuedAt };
}
```

const MAX = 20480;
export function sanitizeCss(css: string): string {
